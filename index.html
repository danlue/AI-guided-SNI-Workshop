AI-guided Structural Novelty Index (SNI)

Draft, version 0.6. This draft is for testing by colleagues. Please do not share it further. When you send comments, please quote the version number and the page.

Overview

This guide contains the step-by-step pages for the 50-minute session on the SNI. The structural novelty index (SNI) asks how far a predicted protein assembly is from a canonical reference, using a set of structural parameters. You will model a hexamer (a ring of six identical protein chains), look at it by hand in ChimeraX, then see how an AI assistant can turn the metric definitions into a script that does the same for many proteins, and check the result. It is based on the preprint listed in the references.

Taking part on your own laptop is optional. The instructor goes through every step on the screen, and you can use this guide to follow along or to repeat it later. Every command has its own Copy button.

How to use this guide

  • Use Next and Back at the bottom of each page, or the numbers in the bar at the top.
  • Switch between English and Japanese with the EN / 日本語 buttons at the top right. Commands, file names and AI prompts are always in English, because the software is used in English.
  • Click Copy next to a command to copy it, then paste it into ChimeraX or Colab.
  • Guide 0 (set-up) is optional: only needed if you want to take part actively on your own laptop. Guide 1 (live modelling) can be done beforehand, because the AlphaFold Server job takes about 7 minutes.
  • Unfamiliar abbreviations are explained on the last page (Glossary).

What pLDDT means

pLDDT (predicted Local Distance Difference Test) is AlphaFold's confidence for each residue (one amino acid in the chain), on a scale from 0 to 100. In ChimeraX with the alphafold palette: dark blue = above 90 (very high), light blue = 70–90 (confident), yellow = 50–70 (low), orange = below 50 (very low, often disordered or flexible). It tells you how well each part is predicted, not whether the assembly is right.

hide #1 surfaces

What it does: hides molecular surfaces on model #1, so you can see the inside.

hide #1 atoms

What it does: hides all atoms shown as sticks or balls, including the oleic acid molecules.

cartoon #1

What it does: shows the protein as a cartoon (ribbons for the backbone, helices as coils). This is the best view for the overall architecture of the ring.

view

What it does: re-centres and zooms so the whole structure fits in the window.

What it does: colours the structure by pLDDT, AlphaFold's confidence per residue. The alphafold palette uses the standard AlphaFold colours.

What it does: gives the chains back their own colours (use this to switch back from the confidence colours).

Look for: which parts are dark blue (confident) and which are orange (low confidence)? The orange regions are usually flexible loops or the ends of the protein.

Step 2 · Read the ipTM 2 min

What ipTM means

ipTM (interface predicted TM-score; TM = template modelling) is one number from 0 to 1 for the whole model. It reflects how confident AlphaFold is about how the chains sit relative to each other, in other words the interfaces. Rule of thumb: above 0.8 = high confidence, below 0.6 = likely a failed assembly, in between = grey zone. A related number, pTM (predicted TM-score), scores the overall fold. ipTM is stored in the summary_confidences_0.json file under "iptm". ChimeraX does not display it.

Open the two summary_confidences files from the confidences folder of the pack in a text editor (Notepad, TextEdit) and find the number after "iptm": NbNRC2a_hexamer_summary_confidences_0.json and NbNRC7a_hexamer_summary_confidences_0.json.

Step 3 · The PAE plot: how sure is AlphaFold about the interfaces? 3 min

What PAE means

PAE (predicted aligned error) is a table with one row and one column per residue. The value at row X, column Y is the error, in Å (angstrom, 0.1 nm), that AlphaFold expects in the position of residue Y if the model were aligned on residue X. Low error means a confident relative position.

Blocks along the diagonal show how well each chain is folded internally. Blocks away from the diagonal show how confident AlphaFold is about how two chains sit against each other, which is what matters for an assembly. Rule of thumb: 0–10 Å confident, 10–15 Å grey zone, above 15 Å poor. The SNI (Structural Novelty Index) uses 10 Å as its cut-off for counting contacts.

In the AlphaFold Server plots, dark green means low error; in ChimeraX, blue means low error.

The next commands load the PAE for each model and draw it as a plot. The files are large (about 80 MB each), so each takes a few seconds.

alphafold pae #1 file pae/NbNRC2a_hexamer_full_data_0_slim.json plot true

What it does: loads the PAE table of model #1 (NbNRC2a) and opens an interactive plot. If you select a box on the plot, the matching residues are highlighted on the structure.

alphafold pae #2 file pae/NbNRC7a_hexamer_full_data_0_slim.json plot true

What it does: the same for model #2 (NbNRC7a).

Look for: the first six blocks on the diagonal are the six chains. Compare the area between the chains (away from the diagonal) in the two plots. Where does AlphaFold show more blue (low error), meaning it is more confident about how the chains sit against each other?

The catch: this is a difference you can see, but not a number. Next we turn it into a number: how many contacts between neighbouring chains is AlphaFold confident about?

Step 4 · Contacts between two neighbouring chains, with their confidence 4 min

In the preprint, a contact is a pair of atoms from two neighbouring chains that are less than 4 Å apart, and it only counts if AlphaFold is confident about it: pairs with a PAE of 10 Å or more are excluded. This is how PAE enters the SNI.

In the ring, chain A touches chains B and F. We look at the A–B interface in both models. The command below finds residues that have atoms within 4 Å of each other and draws a line between them, coloured by PAE.

alphafold contacts #1/A to #1/B distance 4 outputFile contacts_NbNRC2a_AB_all.txt

What it does: finds all residue pairs between chain A and chain B of NbNRC2a with atoms less than 4 Å apart, draws lines coloured by PAE, and writes the list (with distance and PAE of each pair) to a text file in your pack folder. The Log reports how many pairs were found.

alphafold contacts #2/A to #2/B distance 4 outputFile contacts_NbNRC7a_AB_all.txt

What it does: the same for NbNRC7a.

Now keep only the confident ones (PAE below 10 Å, as in the paper):

alphafold contacts #1/A to #1/B distance 4 maxPae 10 outputFile contacts_NbNRC2a_AB_confident.txt

What it does: the same search, but ignores pairs whose PAE is 10 Å or more, and writes only those that remain.

alphafold contacts #2/A to #2/B distance 4 maxPae 10 outputFile contacts_NbNRC7a_AB_confident.txt

What it does: the same for NbNRC7a.

To look at the contact sites, zoom to the two chains:

What it does: zooms to chains A and B of model #1. Use view #2/A,B for NbNRC7a, and view to zoom out again.

What to expect (my own count; ChimeraX may differ slightly):
NbNRC2a, A–B: about 63 residue pairs in contact, about 59 of them confident.

That is exactly what the low ipTM (0.40 vs 0.71) is telling us, now as a count. The SNI parameter Sum_CONTACTS adds this up over all six interfaces.

Build the SNI pipeline with an AI assistant

about 20 minutes

Goal

Turn six metric definitions into a working Python script by prompting an AI assistant, test each piece against a known value, and run it on all 10 models. You are the scientist: the AI writes code, you decide whether it is right. This is the by-hand work from the previous part, done for every protein at once.

Step 0 · Open the prepared Colab notebook 3 min

How to ask: five habits 1 min

  • Say what goes in and what comes out (files, columns, units).
  • Give the exact definition, not just the name of the metric.
  • Ask for small functions you can test one at a time.
  • Test against a number you know. Each step gives one. Do not skip this: an AI can say it did something it did not do.
  • Paste the full error message back when something breaks. Errors are normal.

Step 1 · Give the context and ask for the first piece 5 min

Paste the context and the first request together as one prompt (prompts stay in English). The context is needed only once: in the same conversation the AI remembers it for the next steps.

You are helping me write Python code for a Google Colab notebook. I have AlphaFold 3 models of rings of six identical protein chains (hexamers) of plant NRC immune receptors. Relative file paths (the notebook's working folder is the unzipped SNI_workshop_pack):
- models/{NAME}_hexamer_model_0.cif : protein chains A-F (plus oleic acid ligands in other chains; ignore them)
- confidences/{NAME}_hexamer_summary_confidences_0.json : has the key "iptm"
- pae/{NAME}_hexamer_pae_protein_uint8x8.npz : arrays pae_x8 (PAE in angstrom x 8, uint8, shape N x N; N = protein residues of chains A-F in order), chain_ids, res_ids
Names: CaNRC8, CaNRC9, NbNRC2a, NbNRC3, NbNRC4c, NbNRC7a, SlNRC0, SlNRC1, SlNRC5, SlNRC6.
Libraries installed: biopython, scipy, numpy, pandas, freesasa.
Write short, commented functions I can test one at a time, each in its own code cell. Do only the following now; I will ask for the next piece afterwards.

Write a function load_model(name) that returns the six protein chains A-F (Biopython chain objects) from the CIF, and a function read_iptm(name) that returns the ipTM from the confidences JSON.
Then write ring_order(chains): the six chains form a ring, so order them by angle around the ring centre. Use the centroid of each chain's C-alpha atoms and fit the ring plane with SVD, so that consecutive chains in the returned list are neighbours and the last chain neighbours the first.

Step 2 · Inter-protomer contacts 4 min

Give your AI assistant this prompt (prompts stay in English):

Write count_contacts(name) for the six neighbouring chain pairs in ring order (including last-with-first).
For each pair, count heavy-atom pairs (no hydrogens) closer than 4.0 angstrom between the two chains.
Exclude a pair of atoms if the PAE between their residues is 10 angstrom or more. Use pae_x8 / 8 for angstrom. Use the larger of the two directional values, PAE[i,j] and PAE[j,i]. The PAE rows follow the residues of chains A-F in order, so residue index = (start offset of that chain) + residue number - 1.
Return the mean per interface (total over the six interfaces divided by 6); this is Sum_CONTACTS.
Test on NbNRC2a and NbNRC7a.

Read the code it gives you, put it in a notebook cell and run it.

Check: NbNRC2a: about 178 per interface. NbNRC7a: about 0.5 (almost no confident contacts).
If it fails: if you get far more contacts than this, the PAE filter is probably not applied. Ask: “print how many contacts are removed by the PAE filter”. If everything is zero, check the residue index into the PAE matrix.

Step 3 · Buried surface area 3 min

Give your AI assistant this prompt (prompts stay in English):

Write buried_surface_area(name): for each neighbouring pair of chains in ring order, BSA = (SASA_A + SASA_B - SASA_AB) / 2, where SASA is computed with FreeSASA (Shrake-Rupley, 1.4 angstrom probe) on protein atoms only (no hydrogens, no ligands). Test on NbNRC2a.

Read the code it gives you, put it in a notebook cell and run it.

Check: NbNRC2a about 2,150 Å2 (between about 2,100 and 2,200). If your value is twice that, the AI forgot to halve it.
If it fails: if FreeSASA complains, make sure only protein atoms are written to the temporary file and that the structure is built from the file path first.

Step 4 · Ring symmetry and apex distance 3 min

Give your AI assistant this prompt (prompts stay in English):

Write ring_geometry(name) that returns three numbers.
1. SD_THETA_ROT: for each neighbouring pair of chains in ring order, compute the angle (degrees) at the ring centre between the C-alpha centroids of the two chains, then take the population standard deviation (ddof = 0) of the six angles. A perfect hexamer has six angles of 60 degrees.
2. S_PROTO: the population standard deviation of the six distances from each chain's C-alpha centroid to the ring centre (angstrom).
3. D_APEX: the mean distance between the first residue's C-alpha atoms over all 15 pairs of chains (angstrom).
Test on NbNRC2a.

Read the code it gives you, put it in a notebook cell and run it.

Check: NbNRC2a: SD_THETA_ROT about 0.13°, S_PROTO about 0.05 Å, D_APEX about 21 Å.
If it fails: if SD_THETA_ROT is huge, the chain order is probably wrong (Step 1). If D_APEX is near zero, check that the first residue's C-alpha of each chain was used.

Give your AI assistant this prompt (prompts stay in English):

Read the code it gives you, put it in a notebook cell and run it.

Check: a table with 10 rows. NbNRC7a should stand out: low ipTM (about 0.40) and almost no contacts.
If it fails: run one protein at a time first to find which one breaks, then paste the error back.

The definitions behind the prompts (Data S1 of the preprint)

Show the metric definitions
  • ipTM: from AlphaFold 3 summary_confidences.json.
  • Sum_CONTACTS: heavy-atom pairs within 4.0 Å between adjacent protomers (the individual chains of the ring); pairs with PAE ≥ 10 Å excluded; per interface.
  • BSA_INT_PROTO: buried surface area = (SASA1 + SASA2 − SASAcomplex) / 2 per adjacent pair, FreeSASA, 1.4 Å probe (SASA = solvent-accessible surface area).
  • SD_THETA_ROT: population SD (standard deviation) of the six angles at the ring centre (ideal 60°).
  • S_PROTO: deviation of protomer centroid distances to the ring centre.
  • D_APEX: mean pairwise distance between the first Cα of all chain pairs.

The paper averages three seeds and applies a penalty (confidence bound). We use one model, so our values are close to, not identical to, the published ones.

Step 3 · What does this tell us? 3 min

  • NbNRC7a models poorly as a hexamer: low ipTM and almost no confident contacts. The two chains touch in the model, but AlphaFold is not confident about it. In the preprint, NRC7 was flagged this way, and purified NRC7 turned out to form an 11-protomer ring (about 250 Å across, compared with about 150 Å expected for a hexamer) by negative-stain electron microscopy (nsEM).
  • A low score does not say what the assembly is. It says: this does not behave like the reference hexamers, go and look.
  • We used six of the 11 SNI parameters. The others (the α1 helix geometry, hydrophobicity and the motif distance) need extra inputs such as a MADA motif model.

Limits to keep in mind

  • 10 proteins, and z-scores (each value expressed as standard deviations from the mean) within that set only. The paper compares against canonical reference hexamers and uses 637 proteins.
  • One model per protein, no replicate seeds.
  • The models are CC-NB-ARC truncations, not full-length proteins.
  • Always check AI-written code against numbers you can trust.

ステップ2 · ipTM を読む 2分

ipTM とは

ipTM（interface predicted TM-score。TM は template modelling の略）は、モデル全体について 0〜1 の1つの数値で表されます。鎖どうしの相対的な配置、つまり界面について AlphaFold がどれだけ確信しているかを反映します。目安：0.8 超 = 信頼度が高い、0.6 未満 = 複合体の予測に失敗している可能性が高い、その間 = グレーゾーン。関連する pTM（predicted TM-score）は全体のフォールドを評価する値です。ipTM は summary_confidences_0.json ファイルの "iptm" に記録されています。ChimeraX では表示されません。

ステップ3 · PAE プロット：AlphaFold は界面にどれだけ確信があるか 3分

PAE とは

PAE（predicted aligned error）は、残基ごとに1行・1列をもつ表です。X 行 Y 列の値は、モデルを残基 X で重ね合わせたとき、残基 Y の位置に AlphaFold が見込む誤差を Å（オングストローム、0.1 nm）で表したものです。誤差が小さいほど、相対位置の信頼度が高いことを意味します。

対角線上のブロックは、各鎖がそれ自体でどれだけうまく折りたたまれているかを示します。対角線から離れたブロックは、2つの鎖がどう組み合わさっているかへの確信度を示し、複合体ではこちらが重要です。目安：0〜10 Å = 信頼できる、10〜15 Å = グレーゾーン、15 Å 超 = 不良。SNI（Structural Novelty Index）では、接触を数える際のしきい値として 10 Å を使います。

AlphaFold Server のプロットでは濃い緑が低誤差、ChimeraX では青が低誤差を表します。

次のコマンドで、各モデルの PAE を読み込み、プロットとして描画します。ファイルは大きい（それぞれ約 80 MB）ので、それぞれ数秒かかります。

内容: モデル #1（NbNRC2a）の PAE 表を読み込み、インタラクティブなプロットを開きます。プロット上のボックスを選択すると、対応する残基が構造上でハイライトされます。

内容: モデル #2（NbNRC7a）について同じ操作を行います。

見るポイント：対角線上の最初の6つのブロックが6本の鎖です。2つのプロットで、鎖と鎖の間（対角線から離れた領域）を比べてください。青（低誤差）が多く、鎖どうしの組み合わせに AlphaFold がより確信をもっているのはどちらでしょうか？

問題点：これは目で見て分かる違いですが、数値ではありません。次に、これを数値にします：AlphaFold が確信をもっている、隣り合う鎖どうしの接触は何個あるか？
